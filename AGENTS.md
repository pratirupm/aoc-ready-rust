## Development

Run the site with Bun. The `astro` command is a local dependency, not a global binary:

```
bun install
bun run dev
```

Build and check with:

```
bun run build
bun run check
bun run snippets
bun run lint
bun run stats
bun run links
```

The Rust practice lab lives in `rust-aoc-lab/`. Run its checks with `cargo test` from inside that folder.

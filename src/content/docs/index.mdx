This book starts at the beginning. You do not need to have written a program
before. You do not need Rust, Git, a computer science course, or a fast
machine. You need a terminal, permission to install three free tools, and some
patience with a compiler that talks a lot.

We spend a day on the ground floor: opening a terminal, running a program,
storing values, writing functions, reading errors, and saving work in Git. Then
we climb for seven days. Each day adds one AoC-shaped skill and one small,
original drill. By December you have a toolkit you can open on the first
morning of the event.

## What the lab does

Every chapter adds a piece to a small Rust project called `rust-aoc-lab`. The
pieces are the ones Advent of Code keeps asking for: read the input, model the
grid, search the graph, remember a result, simulate the rules, and do the
arithmetic.

```console
$ cargo test drill03
running 2 tests
test drill03_part1_example ... ok
test drill03_part2_example ... ok
```

The tests are the oracle. When they pass, the code is right on the example.
Then you run it on the real input.

## What you will practise

You will write loops first, keep types concrete, and avoid lifetimes until you have a reason. The compiler will complain. We read the first line of the message together, fix the smallest thing, and run again.

You will also meet the patterns behind the harder days: breadth-first search,
Dijkstra's algorithm, memoisation, cycle detection, interval arithmetic, and a
little modular arithmetic. Some puzzles will still be hard. That is normal. The
field guide tells you what to learn next.

## Who it is for

You should be able to open a terminal and type a command. If you have never
done that, the first ground-floor page shows you. You do not need to know what
a variable is. You do not need Git. You do not need to have solved a puzzle
before.

If you already write code, the ground floor will move quickly. Skim it, do the
drills, and start the ramp.

This book starts where you are, even if that is a blank page. You have never written a program. You may have used a computer for years without opening the terminal, the text window where you type commands instead of clicking. That is a fine place to begin.

Advent of Code is a calendar of small programming puzzles that opens each December. Every day brings a story, an input file made for your account, and two questions about that input. People solve the puzzles in every language and at every level, and they stop when the month gets busy. The event is a reason to practise, not an exam.

This book prepares you to join in with Rust, a programming language known for speed, safety, and a compiler that explains itself at length. We begin with the first command you type, not with a definition you are expected to admire from a distance.

## What you do not need

You do not need to have written a program. Not a loop, not a function, not a line of JavaScript in a browser tab. If you have used a spreadsheet formula, you have met the idea of handing the computer a rule; that helps, but it is not required.

You do not need Rust or Git. Git is a tool that records versions of your files so you can return to a working state when an experiment goes wrong. It appears during the ground floor, when you have something worth saving.

You do not need a computer science degree, a fast machine, or a paid editor. A laptop that runs a web browser will do. We use Zed, a free code editor, and you can read the setup page before you decide anything. You also do not need to memorise syntax. The book keeps the code small, and the compiler will correct you when a bracket goes missing.

## What you do need

You need a terminal, or the willingness to open one. A terminal is a window where you type a command, press Enter, and read the reply. The first ground-floor page shows you how to find it on your machine.

You need permission to install three free tools: Rust, Git, and Zed. On your own laptop, that permission is yours. On a school or work machine, ask the person who looks after it. None of the downloads is large, and none of them needs a credit card.

You need patience. Rust's compiler writes long messages, and some of them will look unfriendly at first. They are not scolding you. They are pointing at a line and telling you what the language expected to find there. We read the first line of the message together, fix one thing, and run again.

## Why there is a ground floor

Most books for beginners assume you have already seen a variable, an `if`, and a loop. A variable is a named box that holds a value. An `if` chooses between two paths. A loop repeats a step. Those ideas are not hard, but they are not instincts either, and a book that skips them leaves a reader guessing.

This one does not skip them. The ground floor is a single prerequisite day, split into seven short pages. We open a terminal, write a first Rust program, store values, make decisions, keep lists, repeat work in loops, group steps into functions, describe data with structs and enums, read errors, borrow values without fear, write tests, and make a first commit. Each page ends with something you can run.

That day exists because the seven days after it move quickly. When Day 2 asks you to walk a grid and mark cells as seen, you will already know what a loop is and how to change a value. The ground floor is not a warm-up you can skip if the words are new. It is the part that makes the rest readable.

## The honest outcome

By December, you will solve many of the early puzzles on your own. You will read an input file, turn it into numbers or a grid, and write a loop that produces an answer. You will recognise the shape of a harder puzzle even when you cannot finish it, and you will know which page or pattern to study next.

You will not master Rust in a week. Nobody does. You will still meet compiler messages you cannot explain, and some puzzles will resist for an evening. That is normal. You will keep learning during the event, often on the day a puzzle asks for something new.

What you will have is a working toolkit, a set of habits, and a project you can keep using when December arrives. That is enough to begin.
